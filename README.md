Stock Market Prediction Using Machine Learning : Built an end-to-end ML pipeline to predict next-day stock price direction (AAPL) using 11 years of OHLCV data; engineered 18 technical indicators (SMA, EMA, RSI, MACD, Bollinger Bands, lagged returns) and trained SVM, Random Forest, KNN, and Logistic Regression models with time-series split; achieved best accuracy of 92.1% with SVM and performed feature importance analysis highlighting momentum-based signals.
